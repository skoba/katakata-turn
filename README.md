# カタカタカタカタターン

架空記念病院の「対処している感」を出す、LT 用サイバー防衛コンソール。実際の監視・攻撃・患者情報の処理は行いません。実行時は外部通信ゼロ、すべて架空データです。

Phase 2 の演出強化まで実装しています。AI アシスタント「ハヤオ」、構成図、外部情報フィードに加え、効果音・HEX・スパークライン・BACKSTAGE・自動再生が動作します。仕様の正本は [SPEC.md](SPEC.md)、実装上の判断は [NOTES.md](NOTES.md) を参照してください。MIT ライセンス。

## 起動

Node.js 20.19 以上の 20 系、または 22.12 以上（この環境では 22.23）と npm を使用します。

```sh
npm ci
npm run dev
```

表示されたローカル URL を Chrome / Edge で開きます。開発サーバーはローカル環境だけで使用します。

本番は次のビルド後、**`dist/index.html` をダブルクリック**してください。ファイルは 2 MB 未満の単一 HTML で、ネット接続・サーバー・追加アセットは不要です。配布時もこの 1 ファイルだけをコピーします。

```sh
npm run typecheck && npm test && npm run build
```

1920×1080 / 1280×720 向けの 16:9 画面です。4:3 では上下に余白が入ります。ブラウザのズームは 100% 推奨です。システムに日本語フォントを用意してください。

## キー操作

| キー                 | 操作                                                   |
| -------------------- | ------------------------------------------------------ |
| 任意キー（BOOT）     | 起動ログをスキップして NORMAL へ                       |
| PageDown / →         | 次のシーン                                             |
| PageUp / ←           | 前のシーン                                             |
| 1〜6                 | NORMAL / DETECT / INCIDENT / COUNTER / RECOVERY / END  |
| 印字キー・Space      | 防御側の架空コマンドを 3〜6 文字ずつ入力               |
| Enter                | COUNTER では 8 秒間のターン演出、他は COMMAND ACCEPTED |
| B                    | BACKSTAGE タイムラインと病院側の集計                   |
| H / ?                | ヘルプ                                                 |
| M                    | 効果音のミュート切替                                   |
| A                    | 自動再生の ON / OFF（各シーン 20 秒）                  |
| T                    | ハヤオが現在シーンの状況を 1 文で報告                  |
| Ctrl+Shift+A         | ハヤオの AUTONOMY を ON / OFF                          |
| R                    | BOOT へリセット                                        |
| F                    | 全画面の開始・終了                                     |
| Esc                  | ヘルプ / BACKSTAGE を閉じる                            |
| F5 / Ctrl+R / Meta+R | リロードを抑止                                         |

**COUNTER 中は印字キーがすべて TERMINAL 入力になります。** 機能操作は Ctrl+B / Ctrl+H / Ctrl+M / Ctrl+A / Ctrl+T / Ctrl+1〜6 等を使います。リセットは **Ctrl+Shift+R**、全画面は **Ctrl+Shift+F** です。AUTONOMY は全シーンで **Ctrl+Shift+A** です。矢印・PageUp / PageDown・Enter・Esc はそのまま使えます。クリッカーの「.」は印字入力です。

ハヤオは用意した台本を 35 字/秒でタイプ表示し、シーンの変化や Enter 演出の各バー完了を実況します。最新 4 発話を表示し、過去の発話は 2 行までの抜粋にして最新 3 件以上の表示領域を確保します（全文はホバーで表示）。保持するログは最大 20 件です。発話開始の短いビープは M のミュートと連動します。AUTONOMY OFF では「…」と `AWAITING HUMAN` を表示し、T を押しても沈黙します。ON に戻すと状況報告を再開し、BOOT リセットでも ON に戻ります。END で B を押すと、BACKSTAGE の横で復旧の裏側について告白します。LLM・外部通信・音声読み上げは使用しません。

ターン演出中は入力を無視します。フラッシュとシェイクは最初の 300 ms の 1 回だけで、3 本のプログレスバー、境界シールドと DR 経路切替、ACCESS DENIED の後に RECOVERY へ移ります。復旧は約 8.5 秒かけて完了します。手動モードでは END へはキーで進めます。BOOT は約 3.6 秒で起動ログを表示し、任意キーを待ちます。

誤リロード防止のため、ページを離れるとブラウザ標準の確認が出ます（ブラウザのジェスチャ要件に依存）。テスト時に不要なら `index.html?nobeforeunload` で開きます。非表示タブでは演出時計が停止し、戻った時点から再開します。

## 5 分 LT での使用例

| トークの位置                       | シーン・操作                                 |
| ---------------------------------- | -------------------------------------------- |
| クラウド移行と通常運用を紹介       | BOOT → NORMAL                                |
| 「ところが接続が不安定に」         | PageDown → DETECT                            |
| 「苦情は病院の管理者へ集中」       | PageDown → INCIDENT、キューを見せる          |
| 「カタカタカタ…ターン！」          | PageDown → COUNTER、文字を乱打して Enter     |
| 「ばばーんと復旧」                 | 自動で RECOVERY、復旧を待つ                  |
| 「裏側では大変な作業が続いている」 | PageDown → END。B で紹介パネルとハヤオの告白 |

効果音は小音量 ON で始まり、最初のキー入力で AudioContext を生成・resume します。キークリック、警告、ターン、復旧チャイム、ハヤオの発話ビープを Web Audio で合成します。M は再生中の音も消音します。音声ファイル・音声読み上げ・外部 API は使いません。

A で自動再生を開始すると、各シーン 20 秒で進みます。COUNTER は自動でコマンドを入力してから Enter 演出（追加 8 秒）を実行し、END の 20 秒後に NORMAL へ戻って周回します。A で手動に戻り、R は BOOT へ戻して自動再生も解除します。自動再生中も手動ジャンプでき、移動先で 20 秒を数え直します。BOOT は任意キーで抜けてから A を押してください。BACKSTAGE は B で開きます。

URL に `?seed=123` を付けると、タイピング・粒子と火花・confidence・HEX・スパークラインの乱数を固定できます。同じ入力と演出時間で再現でき、実時計は通常どおり進みます。無効な値は既定シードへ戻します。走査線・ノイズ・グローは静止効果で、カーソルは 1 Hz、全画面フラッシュは Enter の 1 回だけです。

Phase 3 の包括的 E2E スイート・CI・公開設定は対象外です。

## 文言と構成図の編集

画面の文言・架空データは `src/scenario/` に集約しています。

| ファイル        | 内容                                                   |
| --------------- | ------------------------------------------------------ |
| `messages.ts`   | 共通ラベル、起動ログ、定常イベント                     |
| `scenes.ts`     | シーン名・バナー、ターン演出のタイミング               |
| `systems.ts`    | システム名・状態名                                     |
| `packets.ts`    | 患者情報を含まない医療プロトコルの ASCII 断片          |
| `commands.ts`   | 防御 CLI 台本と擬似出力（各 2〜5 行）                  |
| `complaints.ts` | 苦情の種類と件数                                       |
| `backstage.ts`  | BACKSTAGE 文言・固定タイムライン（集計は共有状態）     |
| `assistant.ts`  | ハヤオの発話・表示文言（オチは `backstageConfession`） |
| `help.ts`       | キー一覧と衝突ルール                                   |
| `topology.ts`   | ノード・リンクの固定座標、名称、攻撃経路               |
| `intel.ts`      | 架空の注意喚起、クラウド基盤・リージョンと状態文言     |

注意喚起の許可された出典ラベル以外に、実在の組織・人名・国名・都市名・製品名・患者識別子を追加しないでください。IP は RFC 5737 の文書用 IPv4 または `2001:db8::/32` の IPv6 だけを使います。変更後に `tests/fictional-data.test.ts` を含む全テストを実行してください。自動検査は全個人情報を判定するものではないため、文言の目視確認も必要です。

NETWORK TOPOLOGY は固定座標の幾何学図形でクラウド・境界・院内の各セグメントを描きます。ノードのランプは SYSTEM STATUS と同じ判定を使い、Enter の隔離完了でシールド、切替完了で DR 経路が点灯します。1280×720 でもラベルは 13px 以上です。

THREAT INTEL は HEX 帯と同居し、注意喚起とステータスページ風のフィードを各 30 件まで保持します。出典ラベルのみ `JPCERT/CC` / `IPA` / `厚生労働省` / `NISC` を使用し、本文は架空要約です。実在の日付・文書番号・URL・脆弱性識別子を追加しないでください。クラウドは架空の「クラウド基盤 A/B」のみです。INCIDENT 中は `intel.ts` の `reloadInterval`（510 ms）ごとにリロード件数、5 秒ごとに最終更新が進みます。30 秒で約 ×58 となり、BACKSTAGE も同じ件数を表示します。苦情対応件数は復旧で解消したキュー件数と共有し、復旧完了時に ×29 となります。NORMAL または BOOT に戻ると件数・フィードを初期化します。

## スクリーンショットと確認

任意の Playwright 撮影スクリプトを同梱しています。`npm run e2e` はビルド済み HTML を **file://、オフライン**で開き、全シーンを撮影します。シーン遷移、連打中の入力ロック、復旧、クリッカー、F5、720p のパネル境界と構成図ラベルの重なり、外部情報の更新・リロード件数共有、ハヤオの状況報告・沈黙・実況・告白、外部リクエスト 0 件、コンソールエラー 0 件も簡易確認します。約 70 秒かかります。`npm run e2e:phase2` は追加で実際の AudioContext の生成・resume・ミュート、ALERT 推移、×58 / ×29、最新 3 発話以上の表示、全乱数の seed 再現性、自動再生の周回を検証し、仮想時間 10 分の DOM・ヒープ上限を確認します。

```sh
npx playwright install chromium
npm run build
npm run e2e
npm run e2e:phase2
```

既存の Chromium を使用する場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chrome npm run e2e`。制限付き Linux 環境で必要な場合のみ `PLAYWRIGHT_NO_SANDBOX=1` を追加します。Linux のライブラリが不足する場合は通常の開発環境で `npx playwright install --with-deps chromium` を実行してください。

出力先は `docs/screenshots/01-boot.png` 〜 `07-end.png`（1920×1080）、演出中・ヘルプ・BACKSTAGE・720p・AUTONOMY OFF・720p の告白・障害中・DR 切替中の追加画像です。Phase 2 検証は ×58 / ×29 の BACKSTAGE を `15-phase2-backstage-{1920,1280}.png` に保存します。Playwright が使えなければ、ブラウザを 1920×1080、ズーム 100% にし、BOOT および 1〜6 各シーンを OS のスクリーンショット機能で保存してください。COUNTER からのジャンプは Ctrl+数字です。

## トラブル時

- キーが効かない: 画面をクリックしてフォーカスを戻し、IME を英数にします。COUNTER では機能キーに Ctrl が必要です。演出中は約 8 秒待ちます。
- 全画面にならない: F（COUNTER は Ctrl+Shift+F）を使用します。ブラウザ側で拒否される場合はブラウザ標準の全画面操作を使います。
- 音が出ない: 最初に画面へフォーカスしてキーを押し、SOUND ON 表示を確認します。M でミュートを切り替え、OS・ブラウザ・出力機器の音量も確認してください。ブラウザが音声を拒否した場合も画面は動作し、次のキー入力で resume を再試行します。非表示タブでは音も消音します。
- レイアウト・日本語が崩れる: 100% ズーム、16:9 の解像度、日本語システムフォントを確認します。
- ビルド済み HTML が動かない: コピーしたものが `dist/index.html` であることを確認し、現行 Chrome / Edge で開きます。開発用のルート `index.html` は直接開けません。
- インストールのキャッシュエラー: `npm ci --cache /tmp/katakata-npm` のように書き込み可能なキャッシュを指定します。

ログは最大 200 行、ターミナル履歴は 100 行、攻撃粒子は 80 個、火花は 96 個（通常粒子は各リンク 2 個）で打ち切ります。HEX は最大 24 行、スパークラインは各 36 点です。描画ループは 1 本です。仮想時間 10 分の自動再生でデータ保持の上限を検証していますが、会場の実機での音量・実時間のフレームレートは事前リハーサルで確認してください。
